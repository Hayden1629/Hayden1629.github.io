# herstrom.com

Minimal static personal site, deployed via GitHub Pages.

- `index.html` — homepage (links, about, guestbook, visitor map)
- `btfc/` — UMN Biotech & Finance Club archive page
- `CNAME` — custom domain (www.herstrom.com)
- `.nojekyll` — serve files as-is, no Jekyll processing

No build step. Edit the HTML, commit, push — Pages redeploys automatically.

Guestbook (atabook.org) and visitor map (mapmyvisitors.com) are third-party
embeds, so they keep working without a backend.
